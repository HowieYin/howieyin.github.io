本期判断：模型的成本竞争正在转向“完成一次有效任务需要多少计算”，推理系统则越来越依赖准确维护前缀、KV、循环状态和物理缓冲边界。小激活参数、低位宽存储与更大缓存容量都不能单独代表低内存、低延迟或可靠部署。

证据说明：性能与质量数据来自厂商、论文作者或 PR 作者实验，本报告未对模型及硬件进行本地复测。价格均为美元 / 百万 Token，特别标注的计费单位除外。百分点、相对增幅、缓存容量、Kernel 时间、整次请求时间与任务成本分别处理；由报告换算的数字标记为计算值。动态文档、榜单与仓库状态以采集时返回内容为准。

本期摘要

  1. GPT-6.2 Astra / Sol、Qwen4-Max 正式版、Gemini 4 Neon 与 MAI Code 2 更新专业任务模型选择。 Astra 标准输入 / 输出为 $8 / $40，Sol 为 $2 / $10，Neon 为 $3 / $15。更少输出 Token 与更好的 Harness 可能降低任务成本，但不同 Benchmark、推理预算和促销价格不能直接拼成统一排名。
  2. 接口升级成为 Agent 能力的一部分。 GPT-6.2 工具调用要求 Responses；历史前缀编辑会丢弃推理项，稳定指令需要放在输入开头。Gemini Tool Retrieval 延迟加载工具完整 schema；应用仍负责真正执行工具。
  3. Inkling 2 Mini 将循环架构带到开放权重与专用运行时。 26.4B 总参数、3.4B 不重复激活参数不等于 3.4B 权重驻留；24 个物理层执行 48 次层访问，vLLM 维护 48 份 KV 与 48 份卷积状态。可变循环实验来自另一个研究 checkpoint。

  5. vLLM 0.34.0 与 TensorRT-LLM 1.3.0 推进状态管理。 vLLM 默认可扩展 KV 可提高容量，也存在 H200 某些并发点 TPOT 上升；TensorRT-LLM 推进 KVCM2、多模态块哈希和状态转移，RC 的已知错误需要与稳定版分开看。

  7. 三篇论文说明 KV 压缩必须与验收、带宽和编码开销一起评估。 Draft KV 量化减少总 KV 约 23.95%，原型却慢 18%～33%；SpecSearch 联合选择 AR / SD 和精度；MiSTiQ 研究约 1.25 有效 bit 的微缩放 trellis 编码，尚非现成生产 Kernel。
  8. 本地硬件与数据中心都有新进展。 RTX Spark 开始提供 Windows on Arm 本地 AI 桌面；AMD / Unsloth 打通 XDNA2 NPU 服务链路。NVIDIA 本期财报营收 $115.844B；Lambda 部署 CPO，AMD ROCm 10.2 推进存储 I/O 和推理工具链。财务增长、HPL、理论算力都不能替代 LLM TTFT / TPOT。

01｜OpenAI：GPT-6.2、前缀语义与长任务计费

事件

11 月 17 日，OpenAI 发布 GPT-6.2 Astra 与 Sol，并同步调整 API 语义与后台任务处理；11 月 19 日更新 GPT Live 1.1 和 WebRTC Standby。Astra / Sol 上线 API、ChatGPT 与 Codex 的相应付费入口。S1、S2

技术解读

最值得检查的是迁移链路。两模型支持 Responses 和 Chat Completions，工具调用要求 Responses。GPT-6.2 在历史前缀被编辑、某些模型切换或最终用户 / 组织改变后丢弃 reasoning items；这可能使模型重复先前工作、增加 Token 并降低答案质量。顶层 instructions 现在放在 input 后面；稳定指令应置于 input 第一条 developer message，顶层字段用于本次请求的临时指导。无存储多轮调用需按顺序回传先前输出，包括加密推理项。迁移还需清理不支持的采样 / logprobs 参数。S3

GPT-6.2 Astra $8 $0.40 $40 标准 Token 价格
GPT-6.2 Sol $2 $0.10 $10 标准 Token 价格

Astra 标准单价相对 GPT-6 Astra 降 20%；缓存价相对旧缓存价降 60%，而相对自身输入价是 95% 折扣。官方 Agents' Last Exam v1.1 报告 Astra 相对 GPT-6 Astra 提高 5.2 个百分点，任务成本不到三分之一；内部 GDPval v2 提高 6.2 个百分点、输出 Token 减少 22%。这些不是统一任务集的公共综合 SOTA。GPT-6.2 不支持 Flex，后台完成窗口也不能当作 Batch 50% 折扣。S1、S2

为什么值得关注

改模型名而保留旧 Chat Completions 工具路径，或者每轮改写历史 developer message，都可能抵消模型升级收益。长任务的队列预算、推理项保留和缓存稳定性开始直接影响 Cost / Task。

判断

优先检查真实调用链：谁重写前缀、谁切换模型、谁回传推理项、谁执行工具。Live 1.1 主要更新多语言发音、口音与转录；Standby 在不活跃时暂停推理、语音输入后恢复，不能由此推断所有空闲计费都免费。官方将 Astra 的部分自我改进能力评为高等级，仍属于特定风险评估，不是自主完成整个研发链路的证明。

02｜Qwen4-Max：从预览到正式 API 与可控历史

事件

延续此前事件。 上期记录 Qwen4-Max-Preview；11 月 16 日正式发布 Qwen4-Max，新增正式模型、开放服务入口及明确的思考 / 缓存接口。S4、S5

技术解读

官方披露 2.4T 总参数、71B 激活参数，原生视觉与 1M 上下文；相比同为 2.4T 的 Qwen3.8-Max，激活参数减少 25%。完整权重和架构实现未同步开放，不能据此推断本地 KV 大小或 Attention Kernel。API 使用 qwen4-max；DashScope 即使纯文本也走相应多模态入口。显式缓存支持手动 / 自动断点、默认 5 分钟或 1 小时 TTL，要求有效精确前缀；该型号的 DashScope 路径不支持这项显式缓存。

CoT summary 需要逐轮启用，并原样回传加密完整推理；摘要不替代历史。同一个模型的多种 API 入口，其状态能力并不完全相同。

性能 / 数据

模型上下文 1,000,000 Token。非思考模式最大输入 991,808、输出 131,072；思考模式最大输入 983,616、总 completion 262,144，默认思考预算 131,072。限制需结合整个请求理解，不能把各上限相加。Work360 厂商评估覆盖 721 个领域，称质量更高、输出 Token 减少 35%、任务成本降低约 60%；该评估并非公共 Benchmark。官方公布隐式缓存输入 $0.075 / MTok，本报告不将未核实的显式写缓存价格填入比较表。

为什么值得关注

正式版的价值既包括能力，也包括长历史可维护性、显式缓存寿命和预算控制。对工具密集、长时工作任务，单次输出更短可能降低成本，也可能遗漏必要结果，需要按任务验收。

判断

继续观察更小开放权重型号；本期不能把承诺当作已开放 Max。官方展示的 CPU 调度器离线加速约 14 倍、数控编程人工时间缩短或药物筛选闭环，分别属于业务系统 / 计算筛选结果，不是模型 Decode 加速或临床疗效。

来源

Alibaba Cloud 正式发布、Qwen4-Max API Guide。S4、S5

03｜Gemini 4 Neon：统一上下文与 Harness 放大效应

事件

11 月 18 日，Google 发布 Gemini 4 Neon，提供 Gemini API、AI Studio、企业服务及相应付费产品入口。S6

技术解读

Neon 面向深度分析与多模态 Agent，提供统一的 1M 文本、PDF、图表、音频和视频上下文，四档思考强度，默认 high。可以作为并行 Agent 的编排模型。工具与子 Agent 的配置会显著改变编码成绩；这部分提升不能全部归因于模型权重。

性能 / 数据

标准输入 / 缓存输入 / 输出为 $3 / $0.15 / $15，思考 Token 计入输出。当前定价文档标明隐式缓存，不支持显式缓存。官方报告 Terminal-Bench 4.1 65.2%、FrontierCode 2.0 high 46.2%。在 SWE-sweep 上 mini-SWE Harness 为 12.8%，Antigravity 为 39.0%，不能把这个差异写成仅靠模型训练获得约三倍能力。厂商称默认 high 的任务成本相对 Carbon 低 32%；Carbon 当前促销单价更低，因此这属于工作负载 / 推理效率比较，非 Neon 单价全面更低。S6、S7

为什么值得关注

统一模态上下文减少外部转录与图像摘要造成的信息损失，但真正的运行成本仍受视频采样、思考 Token、工具结果和历史长度影响。

判断

值得用固定 Harness 比较质量、工具调用数和有效任务成本。官方安全测试中的极低攻击成功率或不诚实率只对应特定测试集及防护条件，不能视为普遍免疫。其他厂商同名 Benchmark 也需对齐版本与协议后才能横向比较。

事件

技术解读

05｜Tencent Hy4-flash：低激活计算与低 KV 是两回事

事件

11 月 16 日发布 Hy4-flash，官方披露混合 Attention、Latent MoE、Engram 和记忆 / 推理路线。S9

技术解读

Flash 为 224B 总参数，其中含 64B Engram，12B 激活参数，原生视觉和 1M 上下文。自蒸馏与 RL 减少输出，运行时结合 4-bit、Megakernel 和 DFly。作为架构背景，Hy4 模型卡披露 Gated DSA + MLA、IndexCache、稀疏 top-2048 与 DFly 复用目标 KV / 稀疏索引；这些细节不能未经证明全部套到 Flash。S10

性能 / 数据

官方称 Flash KV 为 Hy3 的 1/24、Hy4 的 1/6，但未给出统一上下文、dtype 和测量配置。输出 Token 平均减 50%，WorkIndex 平均任务成本约为 Hy4 的 1/20，均为厂商数据。页面报价 Flash 缓存 / 输入 / 输出 $0.003 / $0.070 / $0.281；TokenHub 另有截止 11 月 30 日的促销，本报告不叠加折扣。Decode 超过 150 Token/s 的宣传缺少完整硬件、batch 与长度条件，不能当作特定设备 TPOT。

为什么值得关注

状态压缩、目标 / Draft 复用和少生成 Token 可能同时降低成本；而 12B 激活计算不代表只需驻留 12B 权重。Engram 的驻留与查找代价同样需要关注。

判断

值得追踪实际 Attention 实现及长上下文准确率。Hy4 卡的语言骨干 770B / 49B 激活还不含视觉与 Draft 模块；许可证为 Tencent Hy 条款，不能写成 Apache。仓库创建日不能证明完整权重公开日，本期重点锚定已确认的 Flash 发布。

来源

Tencent Hy4-flash 发布、Hy4 模型卡。S9、S10

06｜Inkling 2 Mini：循环权重、独立状态与专用执行

事件

延续此前事件。 前两期记录 Inkling 2 Small；11 月 20 日 Thinking Machines 发布新的 Inkling 2 Mini 开放权重，vLLM 同日公布支持，llama.cpp 支持 PR 在北京时间 11 月 21 日合并。S11、S12、S50

技术解读

Mini 是 26.4B 总参数、3.4B 不重复激活参数，考虑重复访问后的权重激活量为 5.4B。24 个物理层由 6 个 Prelude、12 个 Core、6 个 Coda 组成，Core 执行 3 次，总计 48 次层访问。各次 Core 从相同 Prelude 输出开始，通过 Attention / MLP 位置的消息读取和低秩控制器利用先前 pass，不能简化为普通隐藏状态连续循环。

每次 pass 有独立 KV 与卷积状态，vLLM 因而维护 48 份 KV 和 48 份卷积状态。24 个物理层中有 20 个滑动窗口、4 个全局 Attention；状态大小还取决于访问次数和窗口回收。多数层使用 NVFP4，末 4 层 MXFP8。运行时融合消息读取、批量控制器 GEMM，并控制 FP32 合并数值顺序；局部 MoE 一致性不等于所有生成结果逐 bit 一致。

性能 / 数据

厂商称总内存 footprint 约 20GB，展示 48GB M5 Pro 离线运行；性能图中的带宽上限不是 Mac 实测 TPOT。Mini 在指定 Harness 下 DeepSWE v1.1 48.2%，ScreenSpot Pro 76.5%，OmniDocBench 1.6 92.8%。

共享 KV 的容量增幅约 10.9%（报告计算），卷积状态仍不共享。研究开关会让同一 Token 的各 pass 覆盖 KV，后续 Token 读取上一 Token 最后 pass 的缓存，因而改变跨 Token 读取语义；不能仅按“更少 buffer”解释。S12、S13

为什么值得关注

循环模型让权重容量与计算深度解耦，也使状态数量与“物理层数”脱钩。只按层数估 KV 或把激活参数当 RAM，很容易低估真实占用。

判断

适合跟踪 DGX Spark、Mac 和专用 vLLM 路径。固定 Mini 会拒绝可变循环 / 共享缓存实验参数；降低研究模型循环次数同时改变质量，需要重新验收。开放权重的具体许可应按模型文件确认，本报告不默认 Apache；新合并支持也不代表所有后续修复均已完备。

来源

Thinking Machines、vLLM Day-0 Support、Variable-loop Research、llama.cpp PR #32694。S11、S12、S13、S50

  4. KV 优化从压缩率走向完整生命周期。 包括写入、编码、hash、分配、回收、传输、冷页和恢复。Draft KV 原型的速度倒退与错误 verifier，SGLang 的物理 stride 修复，说明正确性和状态边界必须先于宣传加速。
  5. 低位宽路线取决于原生执行路径。 NVFP4 权重存储、W4A16、H100 上模拟格式、Blackwell 原生计算与 CDNA3 scaling 是不同层面的事情；量化 / 转换 / Kernel 每一步都可能造成精度损失。
  6. 硬件规模在增长，端侧与数据中心仍有不同瓶颈。 桌面大统一内存和 NPU API 拓宽本地应用；多节点受到互连、路由和内存交换制约，CPO 与存储路径改善的是其中部分链路。总算力、总容量和收入不能直接推导 TTFT / TPOT。
