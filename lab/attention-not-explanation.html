Attention 热力图几乎反过来，模型输出为什么还能不变？

核心结论：Attention 权重决定 Value 的混合比例，却不单独决定信息贡献。在固定 Value 时，不同的合法概率分布可能产生同一个加权向量；因此一张热力图不能自动升级为“模型为什么这样回答”的因果证明。这个反例也没有证明 Attention 一概无用：解释是否可靠，仍要结合模型结构、干预方式与对照实验。

类型：趣味实验 / 可解释性 / Attention。发布：2026-11-09。本次实验只需要 NumPy，不需要下载模型或调用 API。原论文实验、本文构造的数学反例和进一步工程建议分别标注。

延伸阅读：此前 Online Softmax 和 FlashAttention 解释如何算出加权 Value；这次换一个问题：概率算对了，是否就知道模型在依赖什么？ 文章里的 T1–T4 只是位置标签，不赋予真实词义。

1｜看起来最可信的一张图，可能只回答了半个问题

在 VLM 中，我们常画某个文本 Token 对图像 Patch 的 Attention 热力图。某块区域颜色更亮，读者很容易理解成“模型因为看见这里，才给出答案”。在文本模型中，某个词占了 49% 权重，也很容易被当成最重要证据。

Attention 的确在混合信息，但热力图只画混合系数 α，没有画被混合的向量 V。相同的 0.49 乘以不同 Value，经过输出投影、残差与后续层，作用可以完全不同；几个贡献还可能互相抵消。

最简单的类比是调色。两套颜料混合比例可以很不一样，却调出同一颜色，因为颜料本身不独立。想从最终颜色唯一恢复配方，需要知道颜料，而且需要额外的独立性条件。

这次不靠模型讲故事。先用四个二维 Value，构造两张几乎相反的热力图，直接算输出。

2｜经典争论：Attention is not Explanation 发现了什么？

Attention is not Explanation，Sarthak Jain、Byron C. Wallace，Northeastern University，NAACL 2019；arXiv:1902.10186。官方代码是 successar/AttentionExplanation。本文读取原文 v3 与会议记录。[1][2]

论文主要研究带 Attention 的 BiLSTM 编码器，在文本分类、QA、NLI 上检查两个问题：Attention 是否与梯度、Leave-one-out 特征重要性相关；替换 Attention 分布是否一定改变预测。

这些替代重要性指标也不是“解释的真值”。原论文在讨论中承认，它们在非线性网络里的含义与理想相关性阈值仍有局限；低相关性提供警示，不能单独判定哪种解释正确。

作者发现，BiLSTM 的 Attention 与这些重要性指标往往只有较弱或不稳定的相关性；很多样本可以找到与原分布很不同、却产生近似相同预测的反事实权重。论文还测试随机置换，对照非循环的平均编码器等结构。结论与模型和任务有关，不是对所有架构的全称命题。

原论文 Figure 1 的影评例子，两套不同热力图给出几乎相同的负面预测，约 0.01；作者报告该样本随机置换的预测差异中位数约 0.006。这是论文案例，不是本文的复测结果。 当时的 BiLSTM 分类实验也不能直接当作现代多层 LLM/VLM 的测量。

“存在替代分布”对唯一归因构成挑战，但留下另一个问题：替代权重是否能由同一个训练好的 Attention 模块在真实输入上产生？后文会介绍对此的反驳。

3｜四个 Value：没有任何两个完全相同

固定一个 Query、一层单 Head Attention，忽略 Dropout，先只研究加权结果 o = αV。Value 与两组概率如下：

位置 Value 向量 分布 A 分布 B
T1 [0, 1] 0.49 0.01
T2 [1, 0] 0.01 0.49
T3 [1, 2] 0.01 0.49
T4 [2, 1] 0.49 0.01

两组权重都严格大于 0，和为 1。A 几乎全看 T1/T4，B 几乎全看 T2/T3。四个 Value 互不相同，因此这个例子不依赖“重复 Token 的 Value 完全一样”。

直接计算：

oA = 0.49[0,1] + 0.01[1,0] + 0.01[1,2] + 0.49[2,1] = [1,1]
oB = 0.01[0,1] + 0.49[1,0] + 0.49[1,2] + 0.01[2,1] = [1,1]

原因不是 Softmax 计算出错，而是 V₁ + V₄ = V₂ + V₃ = [2,2]。把质量从一对位置移到另一对，输出抵消得刚刚好。

图 1｜同一颜色刻度下的两组合法 Attention 权重。亮点换了位置，加权结果保持 [1,1]。颜色和单元格数字均由本地数据生成，底部注明输出与距离。 打开完整 SVG

把两组分布比较一下：L1 距离 1.92，总变差距离 TV=0.96；TV 最大值是 1，已经很接近最大差异。使用自然对数的 Jensen–Shannon Divergence 为 0.595108 nats，最大值 ln 2≈0.693147。权重差得很大，不代表输出一定差得很大。

4｜这不是巧合：输出只能看到部分权重方向

令 V 有 N 行、dv 列；α 是长度 N 的行向量。寻找另一组 α′ = α + δ，需要：

δV = 0；δ1 = 0；α + δ ≥ 0

第一条让输出不变，第二条保持概率和为 1，第三条保持合法概率。δ 不是要全部为正，而是有些位置加、有些位置减。

本例的方向为 δ = 0.48[−1,+1,+1,−1]。既满足权重和不变，也满足 Value 加权抵消。只讲 V 的零空间还不够：若改变了总概率，得到的向量可能不是 Attention 分布。

将 Value 与全 1 列拼成 C：

C = [V, 1] ∈ ℝN×(dᵥ+1)
δC = 0；自由方向数 = N − rank(C)

当 N > dᵥ + 1，一定存在非零线性自由方向；如果 α 在概率单纯形内部，即有效位置的权重严格为正，就可以沿某个自由方向移动足够小的距离，保持全部条件。本例 N=4、dv=2，C 的秩为 3，剩一个自由方向。

这是一个充分条件，不是必要条件：Value 有额外仿射依赖时，更短序列也可能不唯一。反过来，若 C 满行秩，则固定 Value 和概率归一化条件下，输出能够唯一确定 α。

图 2｜Value 平面里的四个点。两条虚线连接的点对具有同一个中点 [1,1]，对应两套几乎相反的配方。坐标轴和位置标签展示了抵消的几何原因。 打开完整 SVG

Brunner 等的 On Identifiability in Transformers（ICLR 2020）将这种非唯一性放到 Transformer Head 的 Value 与输出投影中讨论，并提出 Effective Attention：移除映射到输出零空间的权重成分，作为补充诊断。[5] 本文显式加入归一化约束，避免把任意零空间向量直接称作合法 Softmax 分布。

Effective Attention 的投影结果可能带负值，也不保证和为 1；它不是可直接替换原始 Softmax 的概率分布。

5｜概率合法，不等于同一个 Q/K 模块能够生成它

对任意严格正且归一化的 α，可令 logitsᵢ = log αᵢ，于是 Softmax(logits)=α。本例 A、B 都能由有限 Logits 产生，脚本验证这一点。

但“存在某个 Logit 向量”与“固定输入、固定 Q/K 参数的模型能够输出这组 Logits”是不同条件。对固定 Q、K，分数已经确定，模型不会自由选择零空间方向。

在一个 Attention 行上强制替换 α，相当于做内部干预：V 和其余计算先保持不变。若该 Head 的 AV 完全不变，其他 Head、残差和后续输入也保持相同时，下游确定性计算自然会相同。但这没有构造另一个原始输入，也没有证明一种新的训练参数能对整个数据集输出替代 Attention。

若要求同时修改完整 Attention 矩阵，还会受到共享 Q/K、Head 维度、因果 Mask 等约束。本例只替换一个拥有四个有效位置的 Query 行；可以对应 Decode 的某一步，不主张它来自任意固定模型的另一组自然生成轨迹。

这道区分很实用：一张“对抗热力图”可以证明局部映射不唯一，却不自动成为另一个同等可信的真实模型解释。

6｜本地复现：报告距离，也报告向量本身

本次在 macOS、Python 3.12.2、NumPy 2.4.6、float64 下运行。除手算例子外，还固定种子 20261109，生成 N=12、dv=3 的随机 Value，通过 SVD 找 [V,1] 的零空间方向。为保持严格正概率，只走到可行边界的 95%，没有追求最大差异。

实验 Attention L1 TV JSD（nats） 输出最大绝对差异
四位置 A → B 1.920000 0.960000 0.595108 0
随机 Value、SVD 等价分布 0.307622 0.153811 0.038938 5.32×10⁻¹⁷
随意交换 A 的 T1/T2 0.960000 0.480000 0.297554 0.48
同一 A/B，改用 V=I₄ 1.920000 0.960000 0.595108 0.48

随机例子的 C 秩为 4，自由方向数为 8；输出约 [-0.221384,0.337357,0.287179]。SVD 基向量符号和退化子空间基在不同数值库中可能不同，所以随机 Attention 的具体数值不必逐 Bit 相同；合法性和输出一致性是复现标准。

这里没有分类标签，因此 Accuracy、Precision、Recall、F1 不适用于这个数学实验。要回答的是概率距离与向量一致性，而不是模型任务正确率。完整 源代码 与 results.json 包含输入、分布、输出、环境与断言。

安装 NumPy 后，下载脚本运行：

python3 experiment.py

最小版本只有几行：

import numpy as np

V = np.array([[0., 1.], [1., 0.], [1., 2.], [2., 1.]])
a = np.array([.49, .01, .01, .49])
b = np.array([.01, .49, .49, .01])
print(a @ V, b @ V)                 # [1. 1.] [1. 1.]
print(np.abs(a - b).sum())          # 1.92
print(np.max(np.abs((a - b) @ V)))  # 0.0

7｜三个反例：不是想怎么换就怎么换

随意置换会破坏抵消。 把 A 的 T1、T2 权重交换，得到 [0.01,0.49,0.01,0.49]，输出为 [1.48,0.52]。概率仍合法，但不再满足 δV=0。因此论文某些样本上随机置换影响很小，不能推广成所有 Attention 都可以随便打乱。

Value 满行秩时，可以唯一恢复权重。 取 V=I₄，则 αV=α。A 与 B 的输出直接就是两套分布，最大差异 0.48，没有可行非零零空间方向。这说明“权重不唯一”依赖 Value 的结构与维度。

微小 Value 变化会让原方向失效。 在手算例子中，把 V₁ 的第一坐标增加 ε，其余不变，沿用原 A/B：

oA − oB = [0.48ε, 0]
ε 输出最大绝对差异
0 0
0.001 0.00048
0.01 0.0048
0.1 0.048

旧方向不再保持输出。但 N=4、dv=2 的条件还在，重新计算新的零空间方向，通常仍能找到局部等价分布。某一对具体权重失去等价性，与整个映射变得唯一，也不是一回事。

若使用硬 Mask，有效支持集才是 N；被 Mask 的位置不能自由加权。若权重在边界上已有零值，零空间不保证任意方向都能移动。FP16/BF16 下还需考虑 Softmax、乘加和归约误差；本文 float64 的零差异不是生产模型 Bitwise 不变的保证。

8｜为什么“亮的 Token”也未必贡献最大？

固定下游线性探针 s = o·w，可以写成：

s = Σᵢ αᵢ(Vᵢ·w)

关注的是某个输出方向上的贡献，就必须同时看 α 和 Vᵢ·w。例如一个权重只有 0.01 的 Value，如果沿 w 的投影为 100，贡献为 1；另一个权重 0.49，但投影为 0，贡献为 0。这只是局部线性教学例子，不是完整 Transformer 的归因公式。

若干预的是 Logits z，通过 Softmax 微分，在固定 V 与线性探针下还有：

∂s/∂zᵢ = αᵢ[(Vᵢ·w) − s]

高权重但 Value 投影接近当前输出时，继续提高该 Logit 的局部影响可以很小。大 Attention 系数与大梯度因此没有必然的一一对应。

更深一层，Transformer 的 Value 已由前面多层混合上下文，位置 i 的 Vᵢ 不等于“原始 Token i 的纯粹信息”。删除一个 Token，可能同时改变许多位置的 Q/K/V、位置编码和 Mask；不能把这种输入干预当作只将 αᵢ 调小的实验。

残差路径和其他 Head 还可能带着同一信息绕过本 Head。只看一张 Head 热力图，通常漏掉了这些路径。

9｜反驳论文为什么叫 Attention is not not Explanation？

Sarah Wiegreffe、Yuval Pinter（Georgia Tech）的 Attention is not not Explanation，EMNLP-IJCNLP 2019，arXiv:1908.04626，质疑的不是上述乘法，而是从实验走到总体结论的方法。[3][4]

核心有两点：Attention 是训练好的模型模块算出来的，不是每个样本上任意独立的自由变量；存在另一套配方，也未必证明原配方不能提供一种有用解释。解释的定义决定应测什么。

作者提出四种对照：训练时强制 Uniform Attention；用多个随机种子校准分布变化；把学习到的权重作为冻结指导，测试较简单的非上下文模型；端到端训练带距离目标的对抗 Attention 模块，而不是只逐样本改概率。

其中 Table 2 的正类 F1 显示，Uniform 基线在不同任务上影响不同：IMDb 的重现实验从 0.902 到 0.879；SST 从 0.831 到 0.822；Diabetes 从 0.775 到 0.706。这些是论文的原表数据，本文没有重新训练这些模型。 Uniform 模型是训练协议的一部分，不等于仅在推理时把某个模型权重换成平均。

该论文也能找到端到端对抗分布，但相比逐样本搜索，它们不那么极端，且在冻结指导的简单模型诊断上表现不同。它支持的是“需要具体评估 Attention 解释的用途”，没有证明所有热力图都忠实。

两篇论文共同给出的好习惯是：先写出解释要声称什么，再设计可证伪的实验。我们要验证的是局部计算敏感性、输入证据、跨样本稳定性，还是仅仅展示信息流？这些目标不能互相替代。

10｜如果要检查 VLM 的 OCR 热力图，应该怎么做？

一个可执行的验证问题是：“在这批 OCR 样本上，亮 Patch 是否比同面积随机 Patch 更影响指定答案 Token 的分数？”这比先问“热力图看起来合理吗”更容易得到有边界的结果。

固定模型、预处理、分辨率、Prompt、答案 Token 对齐与推理模式。先分别记录各 Head/层的分布，避免把跨层平均当成一个真实 Attention 模块。对于 FlashAttention 这类不保存完整概率矩阵的后端，诊断时可能要显式导出或重算分数；还应确认诊断路径的输出与原路径在容差内一致。

然后至少做两种有区别的干预：在单个 Attention 行上替换/屏蔽权重并明确是否重新归一化；在输入图像上遮挡或替换 Patch 后重新跑完整模型。前者测内部通路，后者会连带改变 Q/K/V。两者一起看，才能避免把位置颜色直接当成输入因果证据。

对照应包含同面积随机区域、低 Attention 区域和不同遮挡样式；注意图像遮挡会制造分布外输入。记录输出 Logits/答案概率差异，而不只比较最终字符串：同一个答案可能掩盖概率已经明显改变。真实 OCR 集还应报告字符/词错误率、精确匹配率，或者在明确定义的二元识别任务中列出 TP/FP/TN/FN 与 Precision/Recall/F1。

若想做本文式局部反例，可以导出固定 V 后寻找可行等价 α′，再注入该行；并明确它是否只是一种数学干预，是否满足原始 Q/K 模块的可达性。若改的是输出投影后的映射 T，还应检查 AV 本身有没有改变。当前文章没有运行此类 VLM 评测，以上是后续验证方案。

11｜总结与启发：热力图是线索，解释还需要实验

这次四位置实验留下三个可以反复使用的直觉：权重与 Value 要一起看；输出不唯一并不等于模型自然会生成所有替代权重；局部干预与输入因果效应要分开测。

热力图可以帮助发现模式、定位值得研究的 Head、比较模型处理同类样本的差异。想进一步说“这块文字导致了回答”，就需要把观察转换成干预、对照与可重复的输出测量。

最有意思的地方并不是“图会骗人”，而是我们终于能说清楚图展示了什么：一套内部混合系数。只要知道它没有展示哪些向量、哪些旁路、哪些依赖，就能把漂亮的颜色变成可检验的技术问题。
