RoFormer：旋转绝对位置，为什么内积只看相对距离？

一句话：RoPE 对 projected Q/K 的每一对通道按位置旋转，利用旋转群的差角恒等式，让 attention score 的显式位置项只依赖两位置之差；这不是任意长度外推、单调距离衰减或全面精度提升的保证。

TL;DR：先建立全局 mental model

一段话。 无位置编码的 self-attention 没有独立的顺序坐标；加法位置编码把内容和位置在投影前混合，而不少相对位置方法又需要在 token pair 层加入额外项。RoPE 让每个 token 独立完成一次 Q/K 旋转，再用普通点积自然获得差角。它无需学习一张固定长度的位置表，也不必显式构造 N×N 的相对位置向量。原文在翻译、英语 MLM、GLUE、Performer 和中文法律相似案例匹配上评估：有收敛和长文收益，但 GLUE 是三项升、三项降，长文实验还改变了截断长度，不能说“所有任务更好”。今天最重要的遗产是可复用的相位构造，而不是 RoFormer 的旧榜单成绩。

  • Problem：怎样让 Q·K 显式表达相对距离，又保持每个 token 可以独立编码？
  • Observation：二维旋转保持长度；两个旋转向量的夹角只增加 (n−m)θ。
  • Insight：先投影成 Q/K，再乘位置相关的正交矩阵，而不是把位置加到 embedding 上。
  • Method：head 内 d/2 个二维子空间，各用一个几何递减频率；Q/K 同频、同配对、同位置约定。
  • Result / Boundary：WMT BLEU 27.3→27.5；CAIL test 68.29→69.79（512→1024），但不是同长度的纯 RoPE 因果效应；没有原文 TPOT、TTFT、带宽或显存实测。

1. Introduction：为什么还需要一种位置编码？

Transformer 将序列表示为向量，再让每个 query 与全部 keys 比较。对于不含位置项、且同步置换输入与 mask 的 attention，输出随输入一起置换：它是 permutation-equivariant，不是“输出完全不变”。causal mask 自身也提供方向性，因此不能把“attention 不知道顺序”扩大成“所有 decoder 都没有任何顺序信号”。RoFormer 的问题是如何在可学习的内容比较里，明确表示两 token 的位移。[1, §1]

句子“猫追狗”和“狗追猫”拥有相同 token 集，却应形成不同语义；输入位置坐标影响后续表示。相对关系又比绝对编号更可复用：“相隔 2 个 token”不应仅因为整段文本移动 100 个位置就换一种关系。理想构造需要同时具备局部编码和成对相对性：编码 token n 不必事先知道所有 query 的位置，但最终 score 可以使用两者之差。

Author Claim。 原文主张旋转构造有长度灵活性、长程衰减、linear attention 兼容性和长文任务收益。应把它们拆成不同命题：差角恒等式是代数性质；衰减讨论依赖频谱和 bound；更快收敛是曲线证据；“更适合长文”需要特定训练与评价条件。尤其不能从相位可计算推导“模型在任何长度都能泛化”。

原文贡献不是发现 sin/cos 可以表示位置——Transformer 已经使用它们——而是把 sin/cos 放到 projected Q/K 的乘法旋转里，使相对位置成为内积结构的一部分。2021 年的实验规模和 decoder 应用生态与今天不同，应先理解历史贡献，再讨论其后演进。

5. Conclusions：真正可保留的贡献是什么？

RoPE 把“每 token 的独立绝对旋转”与“pair 内积的相对位移”连接起来，这是清晰、可实现、可复用的构造；block rotations 无额外可训练位置参数，保范数，并能按特定 Eq. 19 方式嵌入 linear attention。旧实验支持一些配置上的收敛/准确率收益，不能证明所有任务、所有长度或所有硬件更优。

这篇论文的重要性远超过 Table 1 的 0.2 BLEU：后来的 decoder LLM、context extension 和 multimodal positioning 反复复用该相位结构。但“后来广泛采用”是外部证据，不应倒灌成 2021 年原文已经评测了这些系统的说法。

6. Implementation Notes：从公式到可测试的代码

6.1 最小 pairwise 实现与 layout 边界

import numpy as np

def rope(projected, positions, base=10000.0):
    dimension = projected.shape[-1]
    if dimension % 2:
        raise ValueError("rotary dimension must be even")
    frequency = base ** (-2 * np.arange(dimension // 2) / dimension)
    phase = np.asarray(positions)[..., None] * frequency
    cosine, sine = np.cos(phase), np.sin(phase)
    first = projected[..., 0::2]
    second = projected[..., 1::2]
    rotated = np.empty_like(projected)
    rotated[..., 0::2] = first * cosine - second * sine
    rotated[..., 1::2] = first * sine + second * cosine
    return rotated

接口与 shape。 最后轴为每个 head 的 rotary dimension；positions 应 broadcast 到 projected 的所有非 channel 轴，例如 [B,1,N] 对 [B,H,N,d]。这里只是 NumPy FP64 教学实现，不是 production CUDA kernel。partial RoPE 时拆出 dr 个偶数通道旋转，剩余 d−dr 原样保留，θ 的分母与 checkpoint 的 rotary dimension 约定一致。

GPT-J adjacent / NeoX split-half。 原文和官方 README 用 adjacent pairs (0,1),(2,3)…；另一种把前后半 (0,d/2),(1,d/2+1)… 配对。经固定通道 permutation，两种形式数学等价，但 checkpoint 必須同步置换 Q/K projection 权重与相位 table。对已有模型只换 rotate_half 代码，不搬权重，不是等价实现；这会改变 learned channel 关系。GQA 下按 KV heads 旋转 K，不要真的复制缓存到所有 query heads。

6.3 Memory / compute / IO：RoPE 不压缩 KV

工程推导，非原文测量。 全长 self-attention 的 score/value 两次乘法约 4 B Hq N² d FLOPs（dv=d，乘加计 2）；causal 有效运算依 kernel 而变。RoPE Q+K 为 O(BN(Hq+Hkv)dr)，每 pair 4 multiplications+2 additions，约 3BN(Hq+Hkv)dr scalar ops，不含 trigonometry/table creation。没有 dr×dr dense matrix 计算。

cache 每层 K,V:[B,Hkv,N,d]，L layers、s bytes/element，总 2LBHkvNds bytes，RoPE 不改 shape。教学配置 L=32,B=1,Hkv=8,N=4096,d=128,s=2，得 536,870,912 bytes = 0.536871 GB = 0.500000 GiB；N=8192 则 1.073742 GB=1.000000 GiB。decimal GB 用 10⁹，binary GiB 用 2³⁰。不是 RoFormer 配置，不能把这个例子当它的显存测量。

cos/sin 可缓存约 N×dr 元素，两张 half-width table 合计这一数量；也可在 kernel 内计算/重用。独立 rotation kernel 增加读写 Q/K、launch 和 table load；fusion 可降低 memory traffic，但需保持 layout、phase 精度和 cache semantics。FlashAttention 避免 materialize N² score，是 IO 算法，可与 RoPE 组合；不是 RoPE 自己把 attention 变成线性。

6.4 最小复现与测试计划

先测旋转范数保持、matrix/elementwise 一致、共同平移 score 不变、complex/matrix 符号一致和 single-frequency 反例；再测 adjacent/split-half 权重 permutation、partial dr、GQA broadcast、padding position IDs、packed reset 与 prefill/decode cache parity。长位置的 sin/cos 先用 FP32/FP64 reference 对照 BF16/FP16，不要只看输出“没报错”。

若重做论文实验：固定 baseline code/checkpoint、数据 split/tokenizer、masked-token policy、seed 和预算，澄清英文曲线 steps；所有 baseline 同长度跑 CAIL，并给置信区间；Performer 对齐 feature order、r、random seeds/redraw 与 denominator。记录 GPU allocation、precision、wall-clock、throughput 和峰值 memory。本文提供机制级验证，不宣称已经重跑 452,500-step 预训练。

7. External Research：Ancestor → RoPE → Descendants

以下内容来自额外一手来源检索；不属于原文 §5 的结论。时间线按首次公开年份，context window 与 score 按来源具体配置，不用产品宣传最大长度替代能力。

7.1 Before this paper：位置关系的不同编码层

2017 Transformer 使用 additive sinusoidal positions；2018 Shaw et al. 在 pair 层引入相对表示；2019 Transformer-XL 将 recurrence 与相对位置结合；2020 T5 使用 bucketed relative bias，TUPE 分开内容与位置，DeBERTa 解耦 content/relative position；2020 Linear Transformers 与 Performer 研究可分解 similarity。[4–8]

RoPE 的切入点不是选出“最好的距离 bucket”，而是构造一类可以在 token 局部执行、在内积 pair 中恢复相对位移的正交变换。其他路线今天仍有用，不因 RoPE 采用广泛就失去其归纳偏置或效率价值。

7.2 After this paper：外推不是把 position IDs 增大就结束

2021 ALiBi 把线性距离惩罚直接加到 logits，是替代路线，不是 RoPE scaling；2023 LLaMA 的 decoder 使用 RoPE，使它成为广为采用的基础组件。2023 Position Interpolation 将 position p 缩到 p/s，让目标长上下文相位落回原训练区间；代价是短程 phase resolution 变小，并需要适应训练。[9–11]

2023 YaRN 按频段选择外推、插值和过渡，并调整 attention scaling；2024 LongRoPE 搜索非均匀频率缩放与位置区域策略，并采用渐进扩展；2025 LongRoPE2 关注低频维相位覆盖不足、needle-PPL guided search 及 mixed-length training，保护长文与短文性能。[12–14]

机制关系。 原 RoPE 定义 pθ；PI 改 p；base/NTK-like scaling 改 θ；YaRN 按频段改 θ 和 score scale；LongRoPE 系列搜索怎么改；它们都不自动减少物理 tokens 或 KV bytes。频率相位数学、训练分布覆盖和系统资源是三条独立轴。

7.3 Multimodal branch：位置不是只剩一条序号轴

2024 Qwen2-VL 的 M-RoPE 为 temporal/height/width 分配通道；2025 VRoPE 将视频空间组织成四个对称方向并衔接文本。它们复用“每对子相位”接口，但解决视觉坐标组织，而不是直接提升语言 context scaling。[15][16]

对应本站 VRoPE 精读：先读本文理解一对通道为什么旋转，再看视频 (t,h,w) 如何变成各对子 position。不要混淆 M-RoPE、VRoPE 和 VideoRoPE，不要把“位置跨度缩小”当成 tokens/KV 压缩。

可继续阅读 MQA：多个读头，共用一份历史：共享 K 仍可按位置旋转；KV head 数决定缓存表示的份数，位置编码决定检索的相对位置语义。

8. Current State / SOTA：截至 2026-10-27 的可核验研究快照

没有一个脱离 benchmark、模型规模和预算的“RoPE SOTA”。 RoFormer 是位置构造论文，不是今天通用 LLM 排行榜候选。相关工作分别优化 effective context、短文保持、训练成本、多模态时空表示；同一个 advertised context limit 也不是同等能力。检索范围涵盖原论文/官方仓库/模型配置及 2026 新论文，但不宣称覆盖了全部后续工作。

可定量对比的 2025 snapshot。 LongRoPE2 原文 Table 2 在同一 LLaMA3-8B base、RULER 13 tasks 平均、128k setting 下：YaRN 49.39、NTK 73.19、LongRoPE 73.40、LongRoPE2 82.03；对 LongRoPE +8.63 score points，relative 11.76%。同表 Phi3-mini-3.8B 的 LongRoPE2 128k 是 58.81，说明同方法跨模型也不同。论文实验有训练/search 等整套配置，不是仅换一个数学式的等预算隔离。不能把该表冠军叫作 2026 全球冠军。[14][17]

最新检索到的 2026 路线。 EndPrompt: Efficient Long-Context Extension via Terminal Anchoring（2026-05，本文访问原文 HTML）用短物理序列保留前段连续内容，再把末尾短 prompt 放到接近目标长度的 position IDs，给模型暴露远程相对距离。其 LLaMA-family 8k→64k 实验报告 RULER 跨长度平均 76.03，LCEG 72.24、LongLoRA 72.95、full-length fine-tuning 69.23；作者提供 代码。这是特定表内比较，不可拿平均 76.03 与上面的单长度 128k 82.03 直接排名；也不能认为位置跳跃等于真的推理了 64k 个缓存 tokens。[18]

9. Critique & My Insights：哪些结论值得保留，下一步怎么做？

Strengths / Novelty。 以一个容易验证的群结构连接局部绝对编码与相对 score；参数轻、易融入标准 attention；频段可扩展为 context scaling 或多维坐标。数学接口和实现的对应性很强，长期价值明显。

Correctness caveats。 最终旋转恒等式严格成立，但源文有 Eq. 4/16/32 等记号问题，中间 complex polar 推导不应当作最一般唯一性证明；long-term decay 应区分合法 bound 与实际 score 单调性。本文勘误和反例不否定有效构造，而是给结论清楚边界。

Experiment quality / Generalization。 覆盖 translation、MLM、GLUE、linear attention 和中文 matching，比单一实验丰富；但 GLUE 下跌、QQP 异常幅度、BERT positional baseline 描述不一致、Figure 3 step 数不一致，以及 CAIL truncation confound 均限制 causal attribution。34GB 数据和连续训练阶段不能当 equal-budget ablation。

Engineering / Scalability / Hardware。 旋转本身 O(Nd)，kernel 可以 fused，硬件依赖不强；完整 attention 和长上下文却仍受 N² compute、KV bandwidth、phase table 与数值精度影响。无需新增位置参数不等于没有 IO、latency、训练和 memory 成本。原文没有性能测试，不能报 speedup。

Reproducibility。 有公式、官方指引、模型下载和 HF 支持；缺少所有实验的 immutable code/config/checkpoint/data version 和 seeds。本文读者可以实现 RoPE，但复现每个分数还需补材料。API 兼容不能替代结果 reproduction。

Hidden trade-offs。 内容与相位耦合是能力来源，也可能制造 OOD；大 base/插值改善长尺度，却改变局部辨别；numerator-only linear rotation 保结构，却丢掉概率权重解释；更多上下文减少截断，却提高 compute/KV 和训练预算。必须同时报告收益和付出的资源。

Possible improvements / 可证伪假设。 对相同 checkpoint 做频段 ablation，控制长度和训练 budget，以“实际 QK channel 能量×phase 覆盖”预测外推失败，再在 unseen length 验证；对 matched-content far-distance retrieval 观察 attention，不只看 avg cosine；把 feature-map order 与 numerator/denominator rotation 分成 controlled ablations；扩展 CAIL 比较同 tokenization、同输入字数和同长度 baselines。若这些控制组不保留原收益，应承认主要收益可能来自长输入或优化路径，而不强归于旋转。

我的核心理解。 RoPE 最优雅的部分不是“位置是一个角度”，而是把相对关系做成可以 factorize 的 token-local 运算。后来每种 scaling 都在处理同一个张力：局部短程分辨率、远程相位覆盖、训练分布和系统预算不能同时免费获得。理解这四条轴，比背“RoPE 支持无限长度”更有用。
