## Method reconstruction

- W4A16/W3A16 weight-only, grouped by input dimension (default g=128). Salient channels are **input columns of W**, identified by mean absolute activation, not isolated largest-weight elements or output channels. 1% FP16 is an observation experiment, **not final mixed-precision AWQ**.
- Paper column convention: W∈R^(d_out×d_in), X∈R^(d_in×T), Y=WX. PyTorch convention X∈R^(B×T×d_in), Y=X W^T. S=diag(s), W'=WS, X'=S^-1 X; exact before quantization, finite precision and quantization break equality.
- Eq1 Q(w)=Δ Round(w/Δ), Δ=max|w|/2^(N−1). This is explanatory simplified quantization, not complete signed saturation/zero-point export specification.
- Eq2 Q(ws)(x/s)=Δ' Round(ws/Δ') x/s.
- Eq3 output error ≈ Δ RoundErr(w/Δ)x vs Δ' RoundErr(ws/Δ')x/s, expected absolute rounding residual ≈0.25 under uniform assumption; signed mean is zero, MSE is 1/12. Δ'≈Δ is not guaranteed. FP16 is not error-free; paper means no additional integer quantization of X or scales.
- Eq4 s*=argmin L(s); L=||Q(W diag(s))(diag(s)^−1 X)−WX||. Code computes FP32 mean squared output difference; objective need not be end-to-end loss.
- Eq5 s=s_X^α; α grid paper [0,1], **actual code 0,0.05,...,0.95** (20 candidates, endpoint1 excluded), clamp1e−4, divide by sqrt(max(s)min(s)). Grid search uses activations and trial outputs; paper “only average scale / no reconstruction” must be qualified as no regression/backprop weight fitting, not no output-MSE evaluation.
- Actual clipping searches group thresholds at 1,0.95,...,0.55 × group absmax, activation-weighted group output MSE; sampled token default512; skips Q/K/Wqkv due to QK interaction. Not all layers blindly clipped.
- Calibration code defaults n_samples512,seqlen512; Figure8 uses sequence length2048. Do not infer all paper experiments use current code defaults.
- Code `pre_quant.run_awq` caches linear inputs on CPU with hooks and moves one decoder block at a time to GPU. Forward `inps` for next layer is computed before scale/clipping applied to current layer. There is no full training pipeline; this is offline calibration/search/export.
- Folding: Norm gamma/bias divided by same s and Q/K/V columns multiplied; SwiGLU **up projection** output rows / bias divided and down columns multiplied; do not commute scales freely through SiLU/GELU or residual branches.
- GQA guard in `auto_scale.py`: only V→O fold when v_proj and o_proj weight shapes match, else skip; shared KV scale must broadcast to query heads. Link existing GQA/MQA readings.
- Real quantizer affine: Δ=(wmax−wmin)/(2^N−1) clamped; z=clamp(−round(wmin/Δ)); q=clamp(round(w/Δ)+z); reconstruction Δ(q−z). Fake quantized tensor is float and does not save memory. Real export stores integer packing and metadata.
- Current official WQLinear at commit **d6e797a42b9ef7778de8ee2352116e0f48a78d61** uses INT16 qweight shape [d_out/4,d_in] for INT4, metadata [padded_groups,d_out] scale and **scaled_zeros**, each activation dtype FP16/BF16; therefore **4.25 bpw at g128** before padding/exclusions, not 4.125. Common packed INT4 zero-point export has 4.15625 bpw; symmetric FP16 scale only has 4.125. Calculator must offer explicitly distinct formats.
- `calculate_zeros_width`: groups rounded to multiple8 for g>=128; g64/32 additional alignment. Widget can calculate ideal no-padding and clearly say tensor layouts can add padding. Qweight int16 container does not imply 16-bit per original weight.
- Runtime `WQLinear.forward`: flattened input token count<8 chooses GEMV else GEMM in inspected revision. Native INT4×FP16 unavailable on tested older hardware, dequantize inside kernel; arithmetic still FP16/BF16, accumulation separately specified.
- Complexity: scale candidates ~20×linear output eval O(T d_in d_out), quantization sweeps O(20 d_in d_out), module inspection can cost attention too; clipping ~10 thresholds and group partial dot products. No dense H∈R^(d_in²) like GPTQ. Layerwise activation buffers and snapshot copies still nontrivial.

## Open audit / implementation suggestions

- Evaluate real diverse calibration including actual image-derived embeddings for OCR/multi-image workflows; text-only success in paper is existence result, not warranty.
- Audit fake→export→unpack roundtrip, exact quant_method/bits/group/signedness/zero point/packing/transposes/bias/RMSNorm folding, per-layer output error and logits, then downstream task metrics. Quantization errors should not be blamed on small model capacity without conversion checks.
- Capture per-op unpack/convert/scale/MMA, register pressure, spill, kernel launches and cache memory; separate cold/load/warmTTFT/prefill/decodeTPOTpercentiles, short/longcontexts and sustainedpower.
- Weight-only AWQ does not lower KVcache bits/head count. Logical KV=2LBTH_kv d_h b_cache; GQA/MQA complementary. Weight footprint n_q(4+metadata/g)/8+n_unquant×2; actual peak adds workspace/activation/KV/vision/runtime/padding.
- Need independent scaling toy, NEON unpack roundtrip, three-format metadata/KV capacity verification before writing widget model; original model/kernel performance is not locally reproduced.
